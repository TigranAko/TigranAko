## 💼 Проектный опыт

### NeuroTest — AI-платформа для обработки тестов
Стек: FastAPI, LangChain, PostgreSQL, SQLAlchemy, Docker, JWT, LLM (Cerebras/OpenRouter), Tavily API

- Разработал бэкенд для парсинга неструктурированных .docx-файлов в структурированный JSON с помощью LLM
- Интегрировал поисковый API Tavily для автоматического поиска правильных ответов на вопросы
- Реализовал полноценную JWT-аутентификацию с хешированием паролей через Argon2
- Построил трёхслойную архитектуру (API → Сервисы → Репозитории) для масштабируемости
- Настроил контейнеризацию через Docker и миграции через Alembic
- Обеспечил автодокументацию всех эндпоинтов через Swagger UI

### Currency Converter API
Стек: FastAPI, SQLAlchemy ORM, SQLite, authx

- Разработал REST API с эндпоинтами для конвертации валют
- Интегрировал внешнее Currency API для получения актуальных курсов 172 валют
- Реализовал систему кеширования, снизив количество запросов к внешнему API на 70%
- Внедрил JWT-аутентификацию для защиты приватных эндпоинтов
- Применил слоистую архитектуру для масштабируемости кода
- Обеспечил автодокументацию API через Swagger

### To-Do List API
